# حذف نویز نمک‌وفلفل با تخمین‌گرهای انقباضی

این نرم‌افزار خروجی مقالهٔ شما را به‌صورت یک برنامهٔ دسکتاپ (رابط گرافیکی)، ابزار خط فرمان و کتابخانهٔ پایتون ارائه می‌دهد.

## سه روش اجرا
۱. **صفحهٔ وب** (`docs/index.html`): بدون نصب؛ مستقیم در مرورگر اجرا می‌شود و تصویر جایی ارسال نمی‌شود. با GitHub Pages منتشر می‌شود و از Edge/Chrome هم می‌توان آن را به‌صورت برنامه نصب کرد.
۲. **نصب‌کنندهٔ ویندوز**: فایل `ShrinkageDenoiser-Setup-*.exe` را از بخش Releases بگیرید و اجرا کنید.
۳. **پایتون**: روش زیر.

## نصب از کد منبع
```bash
pip install -e .
```
(در اوبونتو: `sudo apt install python3-tk`)

## اجرا
```bash
shrinkdenoise-gui
```
۱. «Open image» را بزنید و تصویر را انتخاب کنید.
۲. درصد نویز را با لغزنده یا کادر عددی تعیین کنید (برای تصویری که از قبل نویزی است، گزینهٔ «The image is already noisy» را بزنید).
۳. پایه را انتخاب کنید: میانه (M) یا CFM (C)، و تخمین‌گر E1 تا E6 (پیش‌فرض E6).
۴. «Denoise» را بزنید. سه تصویر دیده می‌شود: ورودی نویزی، خروجی الگوریتم کلاسیک (E0)، و خروجی تخمین‌گر انقباضی؛ همراه با PSNR و بهبود نسبت به E0.
۵. با «Save denoised image» نتیجه را ذخیره کنید.

اجرای اول حدود یک دقیقه برای کامپایل numba طول می‌کشد؛ بعد از آن سرعت حدود ۱۳ تا ۱۸ ثانیه به‌ازای هر مگاپیکسل است.

توضیحات کامل‌تر در `README.md`.
